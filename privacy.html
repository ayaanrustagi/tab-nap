Tab Nap

Privacy Policy

Effective date: July 19, 2026

Summary: Tab Nap only manages your tabs and settings on your device. It does not send browsing content to a Tab Nap server. There is no account.

What Tab Nap does

Using Chrome’s tabs API and tabs.discard, Tab Nap may suspend tabs that have been idle longer than your chosen threshold, subject to your whitelist and protections (active, pinned, audible tabs).

Data stored locally

  • Idle minutes preference
  • Whitelist of hostnames
  • Simple counters / UI state

Via chrome.storage.local only.

Permissions

  • tabs — find idle tabs, discard, wake/reload, badge count
  • storage — preferences
  • alarms — periodic idle checks

Tab Nap does not use host permissions or inject scripts into web pages.

What we don’t do

  • No Tab Nap cloud
  • No selling data
  • No reading page content for advertising

Website

Static site hosting (e.g. GitHub Pages) may log standard requests per the host’s policy.

Changes

Updates will revise the effective date above.
