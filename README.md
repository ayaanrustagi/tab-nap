# Tab Nap — Auto Suspend Idle Tabs

Suspend idle tabs with Chrome’s native `tabs.discard`. Whitelist, protect pinned/audio, wake all.

- **Site:** https://ayaanrustagi.github.io/tab-nap/  
- **Privacy:** https://ayaanrustagi.github.io/tab-nap/privacy.html  
- **Store listing copy:** [STORE_LISTING.md](./STORE_LISTING.md)  
- **Version:** 1.0.1  

## Load unpacked
`chrome://extensions` → Developer mode → **Load unpacked** → this folder.
